# Documentação do CAEPI API

Guias do projeto organizados por objetivo:

1. [Instalação e primeiros testes](INSTALACAO_E_PRIMEIROS_TESTES.md) — configurar o ambiente, iniciar Docker e validar os primeiros endpoints.
2. [Arquitetura](ARQUITETURA.md) — componentes, fluxo dos dados e responsabilidades.
3. [API e integração](API_E_INTEGRACAO.md) — autenticação por chave, consulta de CA, obtenção de PDF e exemplos de consumidor.
4. [Administração e bases oficiais](ADMINISTRACAO_E_BASES.md) — login, módulos da dashboard, inspeção, simulação e importação manual.
5. [Campanhas e processamento](CAMPANHAS_E_PROCESSAMENTO.md) — lotes pequenos, campanhas, estados, relatórios e recuperação de falhas.
6. [Segurança e backups](SEGURANCA_E_BACKUPS.md) — gestão de segredos, chaves, banco, Redis, objetos e recuperação.
7. [Diagnóstico](DIAGNOSTICO.md) — erros conhecidos e comandos seguros de investigação.

O `README.md` da raiz é o caminho mais rápido para instalar e executar o primeiro teste.
